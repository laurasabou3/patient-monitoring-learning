# Patient Monitoring

## Overview

Patient Monitoring is a personal learning project created to understand how modern backend applications are built and deployed.

The project simulates a simple patient monitoring system consisting of:

- Python REST API
- Microsoft SQL Server
- NGINX Reverse Proxy
- Docker containers
- Docker networking

The goal of this project is educational, focusing on understanding concepts rather than building a production application.
